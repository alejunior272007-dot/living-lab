# Living Lab — Sistem Informasi & Jurnal Digital

Aplikasi web berbasis PHP dan MySQL yang dikembangkan untuk pengelolaan data audit, dokumentasi kegiatan, serta pencatatan dan ekspor laporan jurnal secara terstruktur.

## 🌐 Live Demo & Akses Uji Coba

> **Catatan Pembuatan Akun:** Demi menjaga keamanan dan kontrol akses data, aplikasi ini tidak menyediakan pendaftaran mandiri secara publik. Pembuatan akun baru hanya dapat dilakukan melalui otorisasi **Admin** dengan menghubungi pengelola sistem secara langsung.

## ✨ Fitur Utama
- **Autentikasi & Manajemen Akses:** Pembagian hak akses pengguna terkelola oleh Admin serta fitur ubah kata sandi.
- **Manajemen Audit & Dokumentasi:** Pencatatan detail audit lengkap dengan unggahan bukti dokumentasi kegiatan.
- **Jurnal & Ekspor Laporan:** Rekapitulasi jurnal kegiatan harian dan fitur ekspor data laporan.

## 🛠️ Teknologi yang Digunakan
- **Backend:** PHP Native
- **Database:** MySQL / MariaDB
- **Frontend:** HTML5, CSS3, JavaScript
- **Server & Tools:** Apache (Laragon), Git & GitHub
